# esu's Kettu themes

## Echo
Blue on pitch black, with the ECHO shield in the background.

**Install:** Discord → Settings → Themes → **+** → paste:

```
https://raw.githubusercontent.com/esuu2/esu/main/themes/echo.json
```

Custom icons need the Themes+ plugin.

## Font: Chakra Petch
Angular font that matches the theme. **Install:** Discord → Settings → Fonts → **+** → paste:

```
https://raw.githubusercontent.com/esuu2/esu/main/fonts/chakra-petch.json
```

Chakra Petch by Cadson Demak, SIL Open Font License (see `fonts/chakra-petch/OFL.txt`).
